# Uklad_mnozacy

LMH6612MA to są dwa OPAMPy w jednej obudowie. Są R2R output i mają szerokie pasmo.
https://www.tme.eu/pl/details/lmh6612ma/wzmacniacze-operacyjne-smd/texas-instruments/

RC4580IDR to są dwa OPAMPy w jednej obudowie. Będziemy potrzebować dwóch takich kostek - jeden OPAMP zostanie wolny. Są R2R output.
https://www.tme.eu/pl/details/rc4580idr/wzmacniacze-operacyjne-smd/texas-instruments/

LM2903 to komparator analogowy z wyjściem typu open-colector. W obudowie są dwa komparatory - jeden zostanie wolny.
https://www.tme.eu/pl/details/lm2903pt/komparatory-smd/stmicroelectronics/

SH8KC6TB1 to dwa tranzystory n-mos w jednej obudowie. 
https://www.tme.eu/en/details/sh8kc6tb1/multi-channel-transistors/rohm-semiconductor/
